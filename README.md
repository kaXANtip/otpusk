# «Отпуск» — доставка продуктов (Telegram Mini App)

Мини-приложение для Telegram: витрина на 1266 товаров из вашей таблицы, корзина, оформление заказа и бот,
который присылает заказы операторам и сообщает покупателю статус.

Работает без сборки: чистые HTML/CSS/JS + серверные функции Vercel. Внешних зависимостей нет.

## Что умеет

**Покупатель**
- Главная как в Лавке/Самокате: адрес и время доставки, поиск, подборки («Выгодно», «Из Крыма», «Мороженое», «Завтрак»…), баннеры, плитки категорий, витрины по разделам.
- Категории с липкими вкладками подкатегорий, сортировкой и фильтром по брендам.
- Поиск: мгновенный, понимает окончания («молока» → молоко), неверную раскладку («vjkjrj» → молоко), опечатки и разговорные слова («минералка», «пельмешки»).
- Карточка товара в шторке: цена за кг/л, похожие товары, другие товары бренда.
- Корзина: шкала до бесплатной доставки, минимальная сумма, «не забудьте», что делать если товара нет, отмена удаления.
- Оформление: адреса (несколько, с геоточкой для курьера), «как можно скорее» или ко времени (слоты по часам работы), телефон из Telegram в одно касание, оплата при получении (карта / СБП / наличные со сдачей), промокод.
- История заказов с повтором в одно касание, избранное, профиль.
- Светлая и тёмная тема (как в Telegram), нативная кнопка «Назад», вибрация, синхронизация корзины и адресов между устройствами через Telegram CloudStorage.

**Магазин**
- Заказ приходит в Telegram (лично вам или в группу операторов) с кнопками: ✅ Принять → 🛵 Передан курьеру → 📦 Доставлен / ❌ Отменить. Покупатель автоматически получает сообщение о каждом статусе.
- Если покупатель пишет боту, сообщение уходит операторам; ответ оператора (reply) бот пересылает покупателю. На сообщение с заказом тоже можно ответить reply — ответ уйдёт клиенту.
- Сервер сам пересчитывает цены по каталогу и проверяет подпись Telegram — подменить сумму из браузера нельзя.

## Деплой на Vercel

1. **Создайте бота** в [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. **Загрузите проект** на Vercel:
   - через GitHub: залейте папку `otpusk-app` в репозиторий → на vercel.com «Add New → Project» → импортируйте репозиторий. Если в репозитории лежит вся папка `OTPUSK`, укажите **Root Directory = `otpusk-app`**. Framework Preset — **Other**, сборку не настраивайте;
   - или через CLI из папки `otpusk-app`: `npx vercel --prod`.
3. **Переменные окружения** (Project → Settings → Environment Variables):
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_CHAT_ID` — куда слать заказы (см. шаг 5). Можно несколько через запятую.
4. Сделайте **Redeploy** и откройте в браузере `https://ВАШ-ПРОЕКТ.vercel.app/api/setup` — это подключит webhook, кнопку меню «Магазин», команды и описание бота. В ответе будет имя бота и статус каждого шага.
5. **ID для заказов**: напишите боту `/id` (или добавьте бота в группу операторов и напишите `/id` там) → вставьте число в `ADMIN_CHAT_ID` → Redeploy. Готово: откройте бота и нажмите «Магазин».

> Пока `BOT_TOKEN` и `ADMIN_CHAT_ID` не заданы, приложение работает в **тестовом режиме**: заказ можно оформить, но он никуда не уходит, и на экране это честно написано.

Необязательно: в BotFather → Bot Settings → Configure Mini App можно включить Main Mini App с тем же адресом — тогда работает ссылка `t.me/ВАШ_БОТ?startapp` и кнопка «Открыть» в профиле бота.

## Обновить товары

1. Правьте `Таблича.xlsx` как обычно. Если заполнен столбец «Наша цена продажи» — в приложении будет она, иначе «Цена у источника».
2. Пересоберите каталог (нужен только Python 3, без установки пакетов):
   ```
   python tools/build_catalog.py "D:/OTPUSK/Таблича.xlsx"
   ```
3. Задеплойте (git push или `npx vercel --prod`).

Скрипт сам убирает дубли, чистит названия, приводит вес/объём к виду «900 мл», «1,5 кг» и предупреждает о странных значениях.

**Можно добавить в таблицу столбцы** (по заголовку, в любом месте):
- `Фото` — ссылка на картинку или путь вида `/img/products/moloko.webp` (файл положите в `public/img/products/`). Пока фото нет — показывается красивая заглушка;
- `Старая цена` — покажет зачёркнутую цену и бейдж скидки;
- `Описание` — текст в карточке товара;
- `Наличие` — `нет` или `0` скрывает товар.

Оформление категорий (эмодзи, цвета, короткие названия) и подкатегорий — в начале `tools/build_catalog.py`.

## Настройки магазина — `public/data/shop.json`

| Поле | Что это |
|---|---|
| `cities` | Где доставляете (если несколько — покупатель выбирает) |
| `eta` | Обещание по времени, например «30–60 мин» |
| `minOrder` | Минимальная сумма заказа |
| `delivery` | Стоимость доставки по порогам: `{ "from": 0, "fee": 149 }, { "from": 1500, "fee": 0 }` |
| `hours`, `slotHours`, `daysAhead` | Часы работы, длина слота, на сколько дней вперёд можно выбрать время |
| `payments` | Способы оплаты при получении |
| `support.telegram`, `support.phone` | Контакты поддержки (появятся в профиле и в заказах) |
| `botLink` | Ссылка вида `https://t.me/otpusk_bot?startapp` — включит кнопку «Рассказать друзьям» |
| `banners`, `collections`, `popular` | Баннеры на главной, подборки и популярные запросы |

⚠️ Значения доставки, минимальной суммы и часов работы — примерные, поставьте свои.

## Промокоды

`api/_lib/promo-codes.js` (там же описание полей) или переменная `PROMO_CODES` в Vercel.
Код `ОТПУСК10` — **пример**, замените или удалите его.

## Ссылки на разделы

`https://t.me/ВАШ_БОТ?startapp=c_dairy` — сразу открыть категорию (id категорий: dairy, bakery, meat, poultry, fish, frozen, snacks, grocery, drinks, kids, care, pets),
`startapp=col_local` — подборку, `startapp=cart` — корзину.

## Локальный запуск

Нужен Node.js 18+: `node dev-server.mjs` → http://localhost:5173 (переменные можно положить в `.env`, см. `.env.example`).
Только витрина без заказов: `python -m http.server 5173 -d public`.

## Структура

```
public/                 статика (то, что видит пользователь)
  index.html
  assets/css/app.css    дизайн-система, светлая/тёмная тема
  assets/js/            main.js, router.js (навигация), store.js (корзина и пр.), data.js (каталог, поиск), screens/*
  data/catalog.json     каталог — генерируется скриптом
  data/shop.json        настройки магазина
api/                    серверные функции Vercel
  order.js              приём заказа → операторам + покупателю
  bot.js                webhook бота: /start, /id, статусы, переписка
  promo.js              проверка промокода
  setup.js              разовая настройка бота
tools/build_catalog.py  Excel → catalog.json
```
